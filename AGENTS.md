# AGENTS.md

You are working in the store repository for yabbistir extensions. yabbistir is a clipboard history app for macOS. An extension is a folder with a `manifest.json`, TypeScript in `src/`, strings in `locales/`, and tests. The build bundles `src/index.ts` into one `index.js` that runs in **JavaScriptCore, not Node**, inside yabbistir's helper process. The extension only computes and returns data; **the app draws all UI**.

Everything you need is in this file and in `docs/`. Read [docs/getting-started.md](docs/getting-started.md) once, then [docs/concepts.md](docs/concepts.md), and look things up in [docs/manifest.md](docs/manifest.md), [docs/api.md](docs/api.md) and [docs/errors.md](docs/errors.md). Do not guess an API or a manifest field: both references are generated from the code.

## Repository map

```text
extensions/<id>/             one extension per folder; <id> is its reverse-domain id
  manifest.json              what it is, its permissions, what it contributes
  src/index.ts               exports actions, detectors and/or captureRules
  locales/en.json            English strings (required); locales/tr.json optional
  tests/*.test.mjs           node:test tests against the fake host
  README.md, CHANGELOG.md    required
  icon.png                   optional; most use an SF Symbol ("sf:<name>") instead
templates/<kind>/            what `npm run new` copies: action, detector, capture-rule, job
packages/api/index.d.ts      the API's types, @yabbistir/api (copied from the app; do not edit)
packages/api/fake-host.mjs   createFakeHost() for tests (its header lists every option)
schema/                      manifest.schema.json (copied from the app; do not edit), catalog.schema.json
tools/                       new, dev, validate, test, build, docs, catalog, sign, pr-checks; tools/test holds their tests
docs/                        guides; manifest.md and api.md are generated by `npm run docs`
docs/recipes/                six complete example extensions
dist/                        build output (ignored by git)
llms.txt, llms-full.txt      the docs' index, and all docs in one file (generated)
```

Real extensions to learn from: `dev.yabbistir.video-download` (job, exec, network, variants, file result), `dev.yabbistir.link-clean` (capture rule), `dev.yabbistir.jwt` (detector and preview), `dev.yabbistir.translate` (variants, AI, translation).

## Commands

Run every command from the repository's root. Node 22.18 or later; run `npm install` once.

| Command | When |
|---|---|
| `npm run new -- <id> --template <action\|detector\|capture-rule\|job>` | To start an extension. Creates `extensions/<id>/`, which passes validate and test at once. |
| `npm test -- <id>` | After every change to `src/` or `tests/`. Add `--test-name-pattern=<name>` for one test. |
| `npm run validate -- <id>` | After every change to `manifest.json` or `locales/`. Prints file, field, problem and fix per line; exit 1 on errors. With a build newer than the source it checks that build too, `index.js` included; otherwise it notes "not built yet (or out of date)". |
| `npm run build -- <id>` | Before you finish. Bundles into `dist/<id>/`, validates that folder, writes `dist/<id>-<version>.yabext`. Catches Node imports. |
| `npm run typecheck` | Before you finish: TypeScript over every extension's `src/`. |
| `npm run dev -- <id>` | To try it in the app: links `dist/<id>` into `~/Library/Application Support/yabbistir/Extensions/` and rebuilds on change. Long-running; `--once` builds and links without watching. Only when a person asks you to, on their Mac. |
| `npm run docs` | Only when you changed `docs/`, `llms.txt`, the schema or `packages/api`: regenerates `docs/manifest.md`, `docs/api.md` and `llms-full.txt`. Commit the result. |
| `npm run test:tools` | Only when you changed `tools/`, `templates/`, `packages/` or `docs/`. |
| `npm run pr-checks` | Before you open a pull request, with the change committed: every check the pull request gets ([Publishing](docs/publishing.md#the-checks)), for the commits since `origin/main`. Takes a few minutes. |

## Rules

1. **Change only your own extension's folder**, `extensions/<id>/`. One extension per pull request. Do not edit `tools/`, `templates/`, `packages/`, `schema/` or another extension unless that is the task itself, in a separate change.
2. **No Node.** No `fs`, `path`, `child_process`, `http`, `crypto` (Node's), `events`, `util`, `url`, `buffer` imports (not even npm packages with those names), and no `process`, `Buffer`, `require`, `global`, `__dirname`. Use the `yab` API and web standards: `URL`, `TextEncoder`, `TextDecoder`, `atob`, `btoa`, `fetch`, `setTimeout`, `AbortController`, `crypto.randomUUID`, `Intl`. See [docs/errors.md#node-builtins](docs/errors.md#node-builtins). (Tests run in Node and may use `node:` modules; only `src/` runs in the app.)
3. **Fewest permissions.** None is the default and enough for most extensions. Add `network` (with `network.domains`), `exec` (with `requires.tools`), `capture` or `history` only when the extension cannot work without it, and say why in the README. On-device AI, translation, images and files in the work folder need no permission. See [docs/permissions.md](docs/permissions.md).
4. **English is required.** Every key the manifest uses is in `locales/en.json`. Every text a person reads is a locale key in the manifest and goes through `yab.t` in code. Other languages are optional.
5. **Extensions never draw UI.** Return results, tags, preview sections, progress and messages; the app draws them in its calm grey look. No colors, no emoji decoration, no HTML layouts. See [docs/design-guidelines.md](docs/design-guidelines.md).
6. **`exec` arguments are fixed or checked.** Item content goes after `--`; no shell; no options that run other programs.
7. **No data leaves the Mac** except what the action is for, when the person runs it. Never log the item's content or a secret.

## Definition of done

- `npm test -- <id>`, `npm run validate -- <id>` (no errors, no warnings) and `npm run build -- <id>` pass, and `npm run typecheck` is clean.
- Tests cover the main path, each message a person can see, and the expected failures (empty input, missing tool, failed request, cancel).
- `README.md` says what the extension does, gives an example, and explains every permission and tool. `CHANGELOG.md` has a `## <version>` section for the manifest's `version`.
- A change to an existing extension raises its `version` and adds a CHANGELOG section.
- Only `extensions/<id>/` changed (plus the root `package-lock.json` if you added a library).

## The essentials

A transform action, complete. The manifest's text fields are **keys** into the locale files:

```json
{
  "id": "dev.yourname.upper",
  "version": "1.0.0",
  "apiVersion": 1,
  "defaultLocale": "en",
  "name": "name",
  "description": "description",
  "icon": "sf:textformat",
  "author": "your-github-name",
  "license": "MIT",
  "categories": ["text"],
  "contributes": {
    "actions": [
      { "id": "upper", "title": "upper.title", "keywords": "upper.keywords", "input": "item",
        "accepts": { "kinds": ["text", "code"] }, "output": "text" }
    ]
  }
}
```

```json
{
  "name": "Upper Case",
  "description": "Turns copied text into capital letters.",
  "upper.title": "Make upper case",
  "upper.keywords": ["upper", "uppercase", "capitals"],
  "empty": "There is no text to change."
}
```

```ts
import type { Actions } from "@yabbistir/api";

export const actions: Actions = {
  upper: {
    run(item, ctx) {
      const text = item?.text ?? "";
      if (text === "") return { none: true, message: yab.t("empty") };
      return { text: text.toLocaleUpperCase(ctx.language) };
    },
  },
};
```

```js
import { test } from "node:test";
import assert from "node:assert/strict";
import { createFakeHost } from "@yabbistir/api/fake-host";
import { actions } from "../src/index.ts";

const host = createFakeHost({ folder: new URL("..", import.meta.url) });

test("upperCases", async () => {
  assert.deepEqual(await host.run(actions.upper, { kind: "text", text: "hi" }), { text: "HI" });
});
```

- **Exports:** `actions[id].run(item, ctx)`, `detectors[id].validate(item)` / `.preview(item, ctx)`, `captureRules[id].run(item, ctx)`; each `id` matches the manifest.
- **Item:** `kind` (`text`, `code`, `link`, `color`, `image`, `file`), `text`, `url` (links; read `item.url ?? item.text`), `color`, `files`, `image`, `tags`, `copiedAt`. `item` is `null` for `"input": "none"`.
- **Context:** `ctx.language`, `ctx.preferences`, `ctx.variant`, `ctx.target` (`kind`: `finder`, `terminal`, `browser`, `editor`, `other`), `ctx.signal`.
- **Results:** `{ text }`, `{ html, text }`, `{ image }`, `{ link: { url, title? } }`, `{ file }`, `{ files }` (paths in `yab.files.workDir`), `{ none: true, message? }`. Declare it in `output`.
- **Capture rule results:** `{ keep: true }` (or nothing), `{ replace: { text } }`, `{ replace: { url } }`, `{ addToCategory: name }`, `{ ignore: true }`.
- **`accepts`:** `kinds` (required), `pattern` (an ICU regular expression *searched for* in the text or URL after trimming; write `^…$` for the whole text), `tags`.
- **Limits:** hint and preview 500 ms, `validate` 50 ms and synchronous, capture rule 200 ms, action 10 s, job none.
- **No effects** (no network, `exec`, notify, open, AI, translate, history) in hints, detectors, previews and capture rules.
- **Fake host:** `host.run`, `host.hint`, `host.validate`, `host.preview`, `host.capture`; options `http`, `exec`, `ai`, `translate`, `history`, `secrets`, `preferences`, `context`, `now`; records `host.calls`, `host.progress`, `host.notifications`. Errors carry `code`: `await assert.rejects(p, { code: "permissionDenied" })`. See [docs/testing.md](docs/testing.md).

## Common mistakes

| Symptom | Cause | Fix |
|---|---|---|
| `the key "x" is not in locales/en.json` | The manifest names a key the locale file lacks | Add it; a `keywords` key's value is a list of strings |
| `"…" is not a manifest field here` (`unknownField`) | A misspelled or invented field | Check [docs/manifest.md](docs/manifest.md); the store rejects unknown fields |
| `must be a string, not null` (`schemaMismatch`) | `null` in an optional field | Leave the field out |
| `the store validator cannot verify … ` (`invalidPattern`) | `\N{…}` or a `\p{Name=Value}` in `accepts.pattern` | Use plain classes such as `[A-Za-z0-9]`, `\d`, `\p{L}` |
| A pattern that never matches | JavaScript regex syntax, or no anchors | Patterns are ICU: escape a literal `{`, use `(?i)` for case; write `^…$` |
| `"fs" is a Node.js module` / `` `process` is a Node.js global`` | Node code in `src/`, or a library that needs Node | See [docs/errors.md#node-builtins](docs/errors.md#node-builtins) |
| `Cannot find module` / `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX` in tests | A plain `import { … } from "@yabbistir/api"`, a local import without `.ts`, an `enum`, or Node older than 22.18 | `import type`, `./file.ts`, no `enum` or `namespace`, Node 22.18+ |
| `no fake response for GET https://…` | The test did not answer that exact URL | Add it to the fake host's `http`, query string included |
| `toolMissing` in a test | The fake host's `exec` table lacks the tool | Add `exec: { tool: … }` |
| `permissionDenied` in a test | An effect in a hint or detector, a host outside `network.domains`, or a missing permission | Move the effect into `run` of an action, add the domain or the permission |
| `run returned …; expected {text}, …` (`badResult`) | `run` returned a string, or a file outside the work folder | Return a result object; write files with `yab.files.write` |
| `captureRuleTags` warning | `accepts.tags` on a capture rule | Remove it: rules see text and URLs only, never tags |
| The extension turns itself off in the app | Three failures in a row (thrown errors count in actions) | Return `{ none: true, message }` for expected cases; `validate` returns `false`, never throws |
| A `yab.ai` or `yab.translate` call fails in a hint | Hints run without effects | No `hint` on such actions; long ones are jobs |
| The action never appears in the panel | `accepts` does not match the item, or `keywords` do not start with what was typed | Check `kinds` and `pattern`; for a link, use the `link` kind |
| `npm run validate` says "not built yet (or out of date)" | There is no build, or the source changed after it, so `index.js` was not checked | Run `npm run build -- <id>`; `npm run validate` then checks the build too, until the source changes again |

When something is unclear, the generated references are the truth: [docs/manifest.md](docs/manifest.md) for fields, [docs/api.md](docs/api.md) for every type and `yab` function, [docs/errors.md](docs/errors.md) for every message.

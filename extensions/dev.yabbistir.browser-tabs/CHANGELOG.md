# Changelog

## 1.0.0

- First version: your open tabs in Safari, Chrome, Arc, Brave, Edge and Vivaldi as a column. ↵ pastes a tab's link, ⇧↵ a Markdown link, and ⌘C copies the link. Only browsers that are already open are asked, pasting asks only the tab's own browser, and private windows are left out where the browser says which they are.

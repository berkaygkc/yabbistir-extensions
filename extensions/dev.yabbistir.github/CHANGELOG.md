# Changelog

## 1.0.0

- First version: a GitHub column with the pull requests waiting for your review, your open pull requests and the issues assigned to you. ↵ pastes the link, ⇧↵ a Markdown link, and ⌘C copies the link.
- "Paste short reference" on a copied pull request or issue link: `owner/repo#123`.
- "Share as gist" on text and code: a secret gist by default, or a public one, and the gist's link is the result.

# Translate

Two actions for text items, both on this Mac:

- **Translate** to Turkish or English with the system's translation. The source language is detected for you. If the text is already in the target language, you are told so instead of getting a copy back.
- **Summarize** in at most three sentences with Apple Intelligence. Long text is cut to 6,000 characters first, on a character boundary.

If translation or the on-device model is not available (a missing language pack, Apple Intelligence turned off), the app's own message is shown unchanged.

## Permissions

None. Translation and summarizing are services of the app itself, so the extension needs no network and runs no programs.

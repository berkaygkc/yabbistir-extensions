# Changelog

## 1.0.1

- Translations: Chinese (Simplified and Traditional), Japanese, Korean, German, French and Spanish.

## 1.0.0

- First version: a strong password (length, character sets, no look-alikes), a passphrase from the EFF large word list, a PIN, a 32-byte hex key and a 32-byte Base64URL key.
- Randomness only from `crypto.getRandomValues`, with rejection sampling.

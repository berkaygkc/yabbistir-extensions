# Changelog

## 1.0.0

- First version: fix spelling and grammar, make shorter, more formal or friendlier, turn into bullet points, extract action items, draft a reply, explain, and write a commit message or a PR description from a copied diff, all with Apple Intelligence on this Mac.
- Text up to 400 characters (fewer than 150 characters of Chinese, Japanese, Korean or Thai) is rewritten at once; longer text runs as a job with progress and a cancel button, part by part. Explanations, commit messages and PR descriptions always run as jobs.
- Rewrites, lists, replies and explanations stay in the text's language: every language Apple Intelligence speaks is recognized and named to the model, which otherwise rewrote a formal or friendly tone in English.
- A rewrite that comes back cut short is never pasted: a notice says so.
